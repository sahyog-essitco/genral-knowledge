## Notes for Using M-Series Screws

1. **Pitch**
   - Standard coarse pitch listed above  
   - Fine pitch exists (e.g., M10×1.25) for precision or vibration resistance  

2. **Size vs Strength**
   - M-size defines diameter only  
   - Strength depends on grade (e.g., 8.8, 10.9, 12.9)  

3. **Selection Rule**
   - General use &rightarrow; 8.8  
   - High load / vibration &rightarrow; 10.9  
   - Critical / high stress &rightarrow; 12.9  

4. **Clearance vs Tap Drill**
   - Clearance hole &rightarrow; bolt passes freely  
   - Tap drill &rightarrow; used before threading  

5. **Safety Margin**
   - If unsure, increase **grade first**, then size if needed.

## Identifying M-Series Screw Size Using Vernier Caliper

### 1. Unthreaded Hole (Clearance Hole)

- Measure the **inner diameter** using a vernier caliper  
- Match with standard clearance sizes  

| **Measured Diameter (mm)** | **Likely Screw Size** |
|----------------------------|----------------------|
| ~3.2                       | M3                   |
| ~4.2                       | M4                   |
| ~5.3                       | M5                   |
| ~6.4                       | M6                   |
| ~8.4                       | M8                   |
| ~10.5                      | M10                  |

**Rule:**  
- Hole is slightly larger than screw  
- Select the nearest smaller M size  

---

### 2. Threaded Hole (Tapped Hole)

- Measure the **minor diameter** (inner thread diameter)  
- Match with tap drill sizes  

| **Measured Diameter (mm)** | **Likely Thread Size** |
|----------------------------|------------------------|
| ~2.5                       | M3                     |
| ~3.3                       | M4                     |
| ~4.2                       | M5                     |
| ~5.0                       | M6                     |
| ~6.8                       | M8                     |
| ~8.5                       | M10                    |

**Rule:**  
- Measured value ≈ tap drill size  
- Map to corresponding M size  

---

### 3. Quick Reference Rule

- ~3 mm → M3  
- ~4 mm → M4  
- ~5 mm → M5  
- ~6 mm → M6  
- ~8 mm → M8  

---

### 4. Notes

- Clearance holes are always slightly larger than screw diameter  
- Threaded holes measure smaller due to thread depth  
- For precise applications, verify thread pitch using a thread gauge
